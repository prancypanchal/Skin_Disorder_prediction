# 🩺 Skin Disorder Prediction Using Machine Learning

## 📌 Project Overview
This project aims to predict different types of skin disorders using Machine Learning classification algorithms. The model analyzes clinical features and predicts the possible skin disorder category.

## 🎯 Objectives
- Analyze skin disorder datasets.
- Perform data cleaning and preprocessing.
- Apply Exploratory Data Analysis (EDA).
- Build and evaluate classification models.
- Predict skin disorder categories.

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Imbalanced-learn
- Jupyter Notebook

## 📊 Dataset
The dataset contains clinical attributes related to six skin disorder classes:

1. Psoriasis
2. Seborrheic Dermatitis
3. Lichen Planus
4. Pityriasis Rosea
5. Chronic Dermatitis
6. Pityriasis Rubra Pilaris

## 🤖 Machine Learning Models
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- Multi-Layer Perceptron (MLP)

## 📈 Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## 🚀 Objective
To develop a Machine Learning classification model that predicts skin disorder categories based on clinical features.

*Note: This project is for educational purposes only and is not a substitute for professional medical diagnosis.*
